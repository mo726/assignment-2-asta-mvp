# Design Notes

## Selected design approach
The chosen design is a dark fantasy tactical dashboard inspired by a battle-planning board. The visual direction uses deep forest greens, near-black surfaces, and gold accents to suggest a serious, elite preparation environment.

## Visual decisions
- Background: layered dark grid with gentle glow to suggest a strategic war room.
- Typography: serif display for the hero title, with monospace small labels to reinforce utility and tactical theme.
- Color system: green-black base with gold emphasis to separate status from neutral interface content.
- Panel treatment: bordered panels with soft corners and small decorative edges to mimic a premium tactical interface.
- Progress emphasis: gold-filled progression bar and numeric percentage to show momentum toward the final battle.
- Interaction feedback: subtle hover and focus transitions so the checklist reads as an active mission tracker.

## Refinement notes
The design intentionally avoids clutter. The layout uses a two-column desktop composition and collapses to a single-column mobile flow while keeping the task list readable and well-structured. The dashboard keeps the narrative strong without turning the page into a highly decorative mockup.
